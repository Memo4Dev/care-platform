# Spacing and layout

Use the 4px scale: `0, 4, 8, 12, 16, 20, 24, 28, 32, 40, 48, 64, 80px`.

- Default component gap: 8–12px.
- Panel padding: 16–20px; page padding: 32px desktop, 16px mobile.
- Containers: 640px compact, 960px medium, 1200px default, 1440px wide.
- Shell: 240px expanded rail, 64px collapsed rail, 56px top bar, 44px subheader.
- Radius: 4px micro controls, 6px standard controls, 8px groups, 12px only for distinct containers.

Use `shadow-sm` for panels, `shadow-md` for popovers, and `shadow-lg` for modal/drawer surfaces.
