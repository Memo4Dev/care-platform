# Motion

Motion is functional and restrained.

- Use 120–180ms ease-out for control feedback, switch thumb movement, and overlays.
- Use a 1px press translation for active buttons only.
- Do not animate layout shifts, tables, financial values, or navigation on load.
- Respect `prefers-reduced-motion`: remove non-essential transitions.
- Loading states use neutral skeleton blocks; never use decorative spinners where progress is unknown.
