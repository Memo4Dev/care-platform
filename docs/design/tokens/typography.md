# Typography

`--font-sans`: system UI stack for interface copy. `--font-mono`: system mono stack for amounts, IDs, timestamps, labels, and table numerics.

| Token | Value | Use |
|---|---:|---|
| `--text-xs` | 11px | compact labels |
| `--text-sm` | 12px | metadata, table copy |
| `--text-md` | 14px | default UI text |
| `--text-lg` | 16px | section emphasis |
| `--text-xl`–`--text-5xl` | 20–48px | headings only |

Weights: 400 body, 500 controls, 600 values and selected labels, 700 navigation and critical emphasis. Use 1.5 body leading, 1.2 headings, and `.06em` tracking only for uppercase mono labels.
