# Grid / Signal Design System

Grid / Signal is the operational interface system for Northstar OS: precise, compact, and calm through long daily ERP sessions.

## Principles

- Use semantic tokens, never raw color values in components.
- Prefer rules, alignment, and whitespace over decorative card layers.
- Keep dense data scan-friendly with mono numerics and stable columns.
- Pair every status color with a written label or icon.
- Preserve the same semantics in light and dark themes.
