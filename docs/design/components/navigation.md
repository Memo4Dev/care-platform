# Navigation

The desktop rail is 240px wide and lives on `surface`; the top bar is 56px high.

- Group rail items with mono uppercase labels.
- Default links are muted; hover uses selected tint; active uses primary with `on-primary` text.
- Use breadcrumbs for record depth and tabs for peer content views.
- Active tabs use a 2px primary bottom border, not a filled pill.
- At tablet width, collapse the rail to 64px; at mobile, convert it to a horizontal scrollable row.
