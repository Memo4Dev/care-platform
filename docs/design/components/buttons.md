# Buttons

Buttons are 40px high with 6px radius. Use one primary button per action context.

- Primary: `primary` background, `on-primary` foreground.
- Secondary: surface with border.
- Ghost: transparent, for low-priority actions.
- Destructive: destructive border and foreground; reserve confirmation for irreversible actions.
- Disabled: loading surface and disabled foreground; no hover/active affordance.

Hover changes the surface or primary background without reducing text contrast. All buttons require a visible focus ring.
