# Tables

Tables are the core operating surface.

- Use 12px body text, 11px uppercase mono headers, and 12×20px cell padding.
- Right-align numerics and use mono for quantities, amounts, SKUs, and IDs.
- Use horizontal rules; do not zebra stripe.
- Hover uses `surface-subtle`; selected rows use `primary-selected`.
- Preserve a minimum table width and allow horizontal overflow on smaller viewports.
- Pagination sits below the table and communicates position and total count.
