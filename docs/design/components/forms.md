# Forms

Fields are 40px high, surface-backed, and outlined with `border`. Hover strengthens the border; focus uses `focus` ring plus focus border.

- Labels sit above fields and use 12px/600 weight.
- Helper and validation copy use 11–12px; errors state the remedy.
- Form sections use a heading and rule, not nested floating cards.
- Checkboxes are 18px square; radios use an 18px circle; switches are 36×20px.
- Keep related fields in two columns on desktop and one column on mobile.
